### Quadratic Sorts

| Method | Asymptotic Time | Avg Swap | Avg Compare | Space |
|---|---|---|---|--- |
| `Insertion Sort'| O(n<sup>2</sup> | n(n-1)/4 | (n(n-1)/4)+n | O(n) |
| `Bubble Sort` | O(n<sup>2</sup> | n(n-1)/4 | n(n-1)/2 | O(n) |

**Insertion Sort** starts from the beginning of an array and backtracks to previously sorted elements. Swaps any inverted values until a greater or equal value, or the beginning of the array, is encountered.<br>

**Bubble Sort** outer loop starts from beginning of an array and separates sorted and unsorted subarrays. Inner loop starts from end of array and swaps left the lowest encountered value to the start of the unsorted subarray. <br>
